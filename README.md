## About me

Hi, I'm Ping. I'm mostly working with web, even tho somtimes like to mess with ML. My work is focused on:

- **Machine Learning** - experimenting with ASR systems, machine vision pipelines, and practical hardware integrations.
- **Web design** - creating distinctive, responsive websites and tools with close attention to interaction and visual detail.

## Projects

### Museal (currently private, going to be opened ~november 2026)

A self-hosted music library manager for organizing, repairing, and expanding a personal collection. Museal combines library scanning and metadata tools with provider search (Musicbrainz, yandex music, qoubuz and others) and downloads, Navidrome integration, statistics, duplicate detection, iPod sync.
